# IINA 音画逐帧校准器

这个可选的 macOS 面板在 IINA 播放本地有声视频时，按影片的标称帧率逐帧调整声音的试听时序。

## 构建与运行

在 macOS 13 或更高版本安装 Xcode Command Line Tools 和 [IINA](https://iina.io/)。在仓库根目录运行：

```sh
cd tools/iina-frame-tuner
./build.sh
open "build/音画逐帧校准.app"
```

## 试听

1. 点击「选择影片」，打开本地有声视频。新影片默认额外偏移为零。
2. 点击「播放 / 暂停」。在面板内拖动滑块，或按左右方向键，在提前 12 帧到延后 12 帧之间逐帧试听。对于 60 fps，一帧约为 16.67 毫秒；对于可变帧率视频，面板使用 IINA 报告的标称帧率。
3. 勾选「从当前位置循环 5 秒」，可反复比较同一段。面板会在这台 Mac 上按文件路径分别记住所选帧数。

面板显示的数值是**相对于输入文件的额外偏移**。要从零比较全部延迟量，请使用原音轨时序的母版。Music Marbles Studio 默认导出的 MP4 已内含 3 帧声音延迟，试听原有效果时点「归零」。校准只影响 IINA 当前播放，不改写 MP4。
